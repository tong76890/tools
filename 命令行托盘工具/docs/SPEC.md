# 命令行托盘工具

面向 Windows 10/11，使用原生 Win32 C++，不依赖 Qt。托盘工具通过 requireAdministrator 清单请求管理员权限；首次手动启动仍遵循 Windows UAC。

## 行为约定

- 单个实例管理一个命令行程序，启动托盘工具时自动启动目标。
- `tray.ini` 位于工具旁，UTF-8 编码；配置程序路径、原样传递的参数、工作目录。相对路径以工具目录为基准，支持环境变量。
- 默认隐藏共享控制台，托盘菜单提供打开界面、隐藏界面、启动、重启、开机自启和退出。
- 启动不会重复创建正在运行的程序；重启先结束原进程树，再重新读取配置并启动。退出结束被管理的进程树。
- 开机自启指当前用户登录后通过最高权限计划任务启动；默认不启用，由菜单显式设置。
- 配置错误和系统错误显示可读消息，不静默忽略。Explorer 重启后恢复托盘图标。

## 文件与构建

`src/main.cpp` 管理托盘、控制台及进程；`src/config.*` 读取配置；`src/startup.*` 管理任务计划；`src/app.manifest` 声明权限。使用 Visual Studio 2022 的 `CommandTray.sln` 组织源码和构建，入口 README 提供操作说明。

源码使用 C++11 特性、Unicode Win32 API，四空格缩进；VS 使用其默认 C++14 模式编译。使用静态 C++ 运行库，无第三方运行时依赖。源码、文档、测试和辅助脚本分别位于 `src/`、`docs/`、`tests/` 和 `scripts/`；本地输出保存在 `build/`，可执行程序及示例配置打包为 `dist/` 下的 ZIP 发布包。

## 验证

编译实际 Windows 可执行文件，验证配置中的中文、空格、相对路径、参数和无效输入。对进程启动/结束、隐藏/显示和重复启动做运行检查。开机自启代码审查，不在开发机器上自动注册登录任务。需要提升权限的人工桌面操作记录为待验证。交付前独立审查源码、配置、构建和说明之间的一致性。
